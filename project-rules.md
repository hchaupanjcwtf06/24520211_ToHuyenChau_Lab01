# Project Rules — HW1 Production Portfolio

- Use semantic HTML5, modern CSS, and Vanilla JavaScript ES6+.
- Do not use jQuery, Bootstrap, Tailwind, or external script CDNs.
- Use `const` by default; use `let` only when reassignment is necessary.
- Do not use inline JavaScript event handlers such as `onclick="..."`.
- Do not insert untrusted user input with `innerHTML`.
- Use semantic landmarks and a logical heading hierarchy.
- Make keyboard focus visible and verify keyboard navigation.
- Check text contrast for WCAG 2.2 AA; the lab slide calls out at least 4.5:1 for normal text.
- Check both light and dark themes if both are implemented.
- Use CSS custom properties for shared design tokens.
- Verify layout at 375px and check for horizontal overflow.
- Configure and test a CSP appropriate to the actual site.
- Run Lighthouse and record actual results; never invent scores.
- Inspect Git diffs and verify every AI-generated change.
- Implement and commit one atomic milestone at a time.
