# Personal Portfolio — Lab 01

A responsive personal portfolio built with semantic HTML5, modern CSS, and vanilla JavaScript.

## Features

- Responsive layout for desktop and mobile screens.
- Light and dark themes with saved preferences.
- Semantic HTML structure and keyboard navigation support.
- Project, skills, about, and contact sections.
- Contact form that prepares an email using the visitor's email application.
- CSS custom properties for consistent design tokens.

## Technologies

- HTML5
- CSS3
- Vanilla JavaScript (ES6+)
- Git and GitHub


## Run Locally

Open `index.html` in a browser or use the Live Server extension in Visual Studio Code.
